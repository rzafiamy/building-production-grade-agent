# Back Matter

## Reference Material

The following appendices are designed as reference material — pages to return
to when you need a quick lookup, not pages to read sequentially.

- **Appendix A** — Full Lemura API Reference
- **Appendix B** — `SessionConfig` Key Reference
- **Appendix C** — Glossary of Terms
- **Appendix D** — Further Reading and Resources
- **Bibliography** — Works cited throughout the book
- **About the Author**

### How to Use the Appendices

The API Reference (Appendix A) mirrors the TypeScript interfaces and should
be read alongside the source in `src/types/`. When in doubt, the source is
authoritative.

The Glossary (Appendix C) defines every term used in the book with the
specific meaning used here — some terms (like "session", "context") have
broader meanings in other contexts.
