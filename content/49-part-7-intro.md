# Part VII — Real-World Applications

## From Theory to the Real World

### What This Part Covers

- Chapter 37: The Coding Agent — an agent that writes, reviews, and tests code
- Chapter 38: The Research Agent — an agent that searches, synthesizes, and reports
- Chapter 39: The Enterprise Workflow Agent — an agent that automates multi-system business processes
- Chapter 40: What Comes Next — the future of agentic AI

### How to Read This Part

Each case study follows the same structure:
1. **The problem** — what the agent needs to do
2. **The challenges** — what makes this hard
3. **The design** — tools, goals, plans, and configuration
4. **The implementation** — key code in Lemura
5. **The lessons** — what we learned building it

The code in these chapters is condensed for clarity. Full implementations
are available in the Lemura repository examples.

### Why These Three?

Coding, research, and enterprise workflow agents represent three fundamentally
different archetypes:
- **Coding agents** require precision, tool chaining, and iterative correction
- **Research agents** require exploration, synthesis, and uncertainty management
- **Enterprise workflow agents** require reliability, auditability, and human oversight
